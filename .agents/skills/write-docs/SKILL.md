# Write docs

Read the relevant code and existing page. Keep each page focused on one topic and use the site's existing HTML structure, classes, and navigation. Link source files for implementation details.

Use plain language and a diagram or table when it helps. Preserve useful detail without repeating it. Update related pages only when the change makes them inaccurate.

No review, screenshot exercise, style checker, commit trailer, or fixed word limit is required. Publish only when requested.
