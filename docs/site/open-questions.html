Open questions

Design questions that aren't settled yet. Settled ones move to Decisions.

Tasks

QuestionWhere it stands
How should a stalled task be detected?No automatic detector exists. A threshold and notification policy remain undecided.
Does the outer loop catch answers the cited results don't support?No separate system judges the answer. Review finished tasks where the answer and results disagree.
Is $1 the right budget, and are 1 second and 3 restarts the right follow-up values?All are starting values to tune from use.
Should the execution limits change?Model output, activity duration and read retries have limits. Waiting tasks have no expiry. See Inner loop.

Tools and approvals

QuestionWhere it stands
How does the inner loop search the catalog?Every task currently gets the full tool list. Catalog search and selection are not built.
How long do loaded schemas live?No schema loader exists. Lifetime and invalidation rules remain undecided.
Should the calendar's OAuth app leave Google's testing state?Its refresh token expires after 7 days until it does. Google requires completed branding before publishing.
How do standing permissions work, and how are they revoked?Not chosen. Calendar writes and email sends always ask. Shell and browser calls have no approval step.

Memory

QuestionWhere it stands
Should inner loops see saved memories?Today the outer model copies any preference a task needs into its request.
How should long task histories shrink?Storage limits cap task history, but every model call still receives the whole transcript. Task-history compaction is not built.
Should a reply offer to save preferences it wasn't asked to keep?The instructions allow an offer and save only after a yes. No scenario checks it yet.

Schedules and proactive messages

QuestionWhere it stands
How does the user turn off a kind of offer?Dismiss stops one offer. There is no setting for a whole kind yet.
What triggers come after the calendar check?Not chosen.
Should the read-only task's times be checked again at delivery?It reads the calendar at check time, hours before the offer appears.

Clients and operations

QuestionWhere it stands
How does a client other than the web client sign in?Not chosen. Today only the Next.js server calls the hosted service, with a Google token, and the Go handlers read no client credentials.
When does device revocation become necessary?Only once a second client exists.
What would running the computer on another cloud need?A new adapter for the computer provider, and host setup written for that cloud. Only the Compute Engine and loopback adapters exist.
How much do cold starts and scale-in cost in time and money?Measure on the deployed path.
