Tasks

QuestionWhere it stands
How does the outer loop check on a running task?Read the saved status and progress without disturbing the task.
What counts as stalled?No progress event for N minutes becomes a failure-like event. The threshold isn't set.
Does the outer loop catch answers the cited results don't support?No separate system judges the answer. Review finished tasks where the answer and results disagree.
Is $1 the right budget, and are 1 second and 3 restarts the right follow-up values?All are starting values to tune from use.
What bounds apply to run duration, retries and output size?Not set.

Tools and approvals

QuestionWhere it stands
How does the inner loop search the catalog?Not chosen. Every task gets the same tool list until milestone 10.
How long do loaded schemas live?Cache while stable, and drop them when an account or tool changes.
Should the calendar's OAuth app leave Google's testing state?Its refresh token expires after 7 days until it does. Google requires completed branding before publishing.
How do standing permissions work, and how are they revoked?Not chosen. The first proof is one bounded calendar write.
When does an approval expire, and which changes count as material?Changing the recipient, content, date or account invalidates it. The rest is open.

Clients and operations

QuestionWhere it stands
Does a future client gateway share the Go binary?Same binary with separate roles is the proposal.
How does a client other than the web client sign in?Not chosen. Today only the Next.js server calls the hosted service, with a Google token, and the Go handlers read no client credentials.
When does device revocation become necessary?Only once a second client exists.
What would running the computer on another cloud need?A new adapter for the computer provider, and host setup written for that cloud. Only the Compute Engine and loopback adapters exist.
How much do cold starts and scale-in cost in time and money?Measure on the deployed path.
