The architecture reference lives on this site. When prose disagrees with the code, the code and contracts-check decide what runs today.

How Dokyu stays truthful

  • Every page includes a repo-only Sources block pointing at the concrete Go, TypeScript, schema or integration files behind its claims.
  • docs/publish.py strips those repo-only source blocks and omits code.html and sources.html when building a clean static export.
  • core/cmd/contracts-check -strict verifies that JSON Schemas, Go decoders, generated TypeScript types and live HTTP scenarios match.
