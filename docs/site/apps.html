Extension registry

Every tool is registered as a versioned extensions.Definition.

  • A definition has a stable ID, a model-facing name, a JSON Schema input, an execution binding and a policy that sets effect class, location, retry behavior and timeout.
  • A content digest covers everything that affects what a call does.
  • When a task proposes a call, the runner saves the digest on the OperationRecord.
  • Approvals, evidence checks and crash recovery use that saved digest, even after an MCP server updates its schema.

MCP tool bus

core/internal/connectors/mcp connects Nori to enterprise tools and the host app's MCP gateway. Users or hosts manage servers through /v1/mcp:

  • Remote Streamable HTTP servers: Discovery runs on connect and refresh. Each discovered tool becomes a definition named mcp/<server>/<tool>, and its version hashes its description and input schema. In hosted environments, core/internal/netguard blocks outbound URLs to private and metadata addresses.
  • Advisory annotations: Nori treats a remote server's tool annotations as advisory. Discovered MCP tools default to effect unknown and require an approval card or explicit allow rule.
Local servers, resources and prompts, and mid-call input
  • Local stdio servers (development only): When NORI_CLOUD=local, a server can bind to an allowlisted command_ref declared in NORI_MCP_COMMANDS. API requests never pass raw command lines.
  • Resources and prompts: When an MCP server exposes resources or prompts, Nori adds read-only tools to list and read resources and to list and get prompts.
  • Interactive input: If an MCP server requests user input mid-call, Nori cancels the blocking call and gives the task a durable question. The user answers without an open connection.

Provider-agnostic connections port

core/internal/connections manages account lifecycles behind /v1/integrations and /v1/connections. Its connections.Integration interface covers OAuth, grants, resource selection, health, disconnect and user preferences.

StepWhat the port enforces
Connect and callbackOAuth start returns a one-time PKCE and state attempt bound to the signed-in user and integration. Replayed or cancelled callbacks create nothing.
Credential storagecore/internal/secret/rowstore saves bearer tokens and OAuth client credentials in Postgres, envelope-encrypted with a 32-byte key or AWS Secrets Manager. The API never returns raw secrets.
Scoped useThe executor requests credentials for one connection ID. A failed write is never retried on another account.
Health & disconnectEach connection reports one health state, such as ready, needs_sign_in or revoked. Disconnect closes new calls before revoking.
  • The private Google Workspace beta gives designated testers Google Calendar, user-selected Drive files and Gmail sending.
  • Enterprise deployments add internal tools through MCP servers or adapters that implement connections.Integration and invoke.Adapter.

Scripts of tool calls (compose)

When a step needs many calls whose results are combined, the task model can send one compose script instead of calling tools one at a time. A script is versioned JSON, and it makes up to 64 calls, at most 8 at once.

  • Every call inside a script is a recorded operation with its own permission check, approval and digest pin.
  • After a worker restart, finished calls are reused and completed writes are not resent.
  • If a call needs user approval, the script pauses on that interaction and resumes once the user answers.
