Task transcript

Each task saves its messages, tool calls and tool results, and one adapter turns them into a model request.

FirestoreHolds the transcript as private history blocks. Temporal carries references.
↓ transcript
Task activitiesLoad the transcript and call the model. They import no provider package.
↓ instructions, transcript, tool list and output limit
OpenRouter adapterBuilds the Responses request, reserves spend and reads the cost.
↓ Responses request
OpenRouterReturns the turn, its tool calls, usage and cost.
↺ activities append the turn and each tool result to the transcript in Firestore

An example

For the request "What is the title of example.org?", the transcript holds the saved turns below. The model asks for a page, receives it, and proposes an answer. Provider state is what the model provider returned for a turn, such as reasoning and call IDs, kept exactly so it can be replayed.

RoleParts
userText: the request.
modelProvider state, then a browser_navigate call.
userThe result of that call, with the page title and an evidence reference.
modelProvider state, then a complete call with the answer.
Saved form
Transcript typeSaved JSON
Message{"parts": [...], "role": "user" | "model"}
Text{"text": "..."}
Tool call{"functionCall": {"id": "...", "args": {...}, "name": "..."}}
Tool result{"functionResponse": {"id": "...", "name": "...", "response": {...}}}
Provider state{"thought": true, "thoughtSignature": "..."}, where the signature is base64 of nori.responses: followed by the output items OpenRouter returned.

The field names come from the Gemini SDK, which the transcript used before it had its own types. Blocks saved earlier still read. Older workers can read new blocks.

Blocks from the Gemini period also hold thought text and binary signatures. They read without error, and the model is never sent those parts.

The OpenRouter adapter replays a turn exactly when it carries provider state the adapter wrote. It rebuilds every other turn from its text, tool calls and tool results.
