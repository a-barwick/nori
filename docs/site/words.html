Words we use

The same words mean the same things on every page.

WordWhat it means
host appThe internal enterprise agent front-door that embeds Nori headlessly via integrations/embed/adapter.mjs.
Outer loopThe part of Nori (core/internal/conversation) that holds one persistent thread per user and runs one short turn at a time.
Inner loopThe Postgres-native task runner (task.Runner) that executes one task: call the model, run tools, save results and repeat.
RuntimeGo code around the loops that validates calls, enforces permissions, saves records in Postgres and delivers commands. It is not a model.
Agent serviceThe Go service in core/ (nori / nori-local) that the host app and the test workbench call.
TaskOne piece of independent background work, keeping one stable UUID from dispatch until completion, failure or cancellation.
TurnOne run of the outer loop, from claiming pending inputs to publishing a reply.
AttemptOne saved try at an outer turn. A follow-up message restarting the turn creates a new attempt.
DispatchThe outer loop starting a new task (verified by a second model call that sees only user messages and task IDs).
SteerNew instructions for an unfinished task. Earlier constraints stay unless replaced; open approvals are superseded.
CommandA saved instruction going to a task: start, steer, answer, stop or subtask_result.
EventA saved report coming back from a task (needs_input, result, failure, stopped). A log event is a separate ordered entry on the SSE stream.
Log eventA numbered entry in Postgres's event log naming a message, task, result or read position that changed. See Service API.
InboxEither the ordered Postgres queue of pending inputs for the outer loop (conversation_inputs), or the user-facing in-app inbox (/v1/inbox) for automation deliveries.
AcceptedCommitted to Postgres. It does not mean the downstream worker has applied it yet.
AppliedA task workflow has read the command by position and incorporated it into its transcript.
RevisionAn integer that increments on edits or task instruction changes so stale updates and approvals are caught with HTTP 409.
PositionWhere a command sits in a task's ordered list, or where an SSE client sits in the event log.
Lease and fenceHow one outer turn claims a user's conversation in Postgres, and how a stale turn is prevented from publishing.
OperationOne tool call with a stable ID and pinned tool definition digest, recorded before dispatch.
Action digestA SHA-256 hash over a tool call's exact target, arguments and recipients that binds an approval card to one exact action.
InteractionA typed pending request (question or approval card) under /v1/interactions with optimistic revision checks.
Lease table / wake tablenori_task_leases and nori_user_wakes in Postgres, updated transactionally with records so workers discover due work immediately via LISTEN nori_wake or fallback polling.
ProjectionA display copy of task or connection state stored in Postgres alongside authoritative TaskControl checkpoints.
Work request & subtaskA task's request for bounded side work (request_work) settled by the outer loop dispatching up to 4 subtasks that share the parent's budget and stop with it.
CapabilityOne entry in the inner loop's tool catalog (e.g. Web search, Attached files, or an MCP server). Optional capabilities load tool schemas on demand via capability_load.
MCPModel Context Protocol. Nori connects to enterprise remote Streamable HTTP (or local dev stdio) MCP servers via core/internal/connectors/mcp.
Saved resultA versioned record of a task's answer, file or link with a stable ID, cited evidence and delivery timestamps. See Results and files.
JevThe optional fast classifier (jev-latest) that marks nine intent labels as an advisory hint for the outer loop. It grants no authority.
Workercmd/nori --role=worker (or --role=all / nori-local), running worker.Pool for outer turns, due automations and inner task runners.
TranscriptThe ordered messages, tool calls, tool results and provider state of one task, stored as private history blocks in Postgres.
Trace and spanA span is one timed operation (such as a model or tool call); a trace links spans sharing a W3C trace ID. See Observability.
Pause & StopPause blocks new task admission system-wide while chat stays available; Stop cancels one task and its subtasks.
