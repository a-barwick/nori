ProceduresWays of doing recurring work“Do it this way next time.”

What every memory carries

  • Where it came from, and whether the user said it or Nori inferred it.
  • How widely it applies.
  • A way to inspect, correct and forget it.

A forget request reports exactly what was deleted. Removing a preference doesn't erase old messages.

Keeping context small

  • The inner loop looks up more when it needs to.
  • Large tool output lives outside the prompt, with a short summary and a reference.
  • Summarizing old context keeps constraints, corrections, open questions and links back to the originals.
  • Saved history is never deleted to save context.
  • Tool discovery counts against the same context budget.
