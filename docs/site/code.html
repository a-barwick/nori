Code map

Where to look when you want to read or change something.

Go code is under core/. The web client, including its Chats tab, is under web/src/. Dependencies run in one direction: entrypoints build an app, whose api routes call conversation or chat, which use state and dispatch.

Code reaches infrastructure through small contracts: wake sends wakes, dispatch delivers saved commands to Temporal through an orchestration contract, and secret reads credentials. Cloud Tasks, Temporal and Secret Manager are the adapters today. Only task and the worker code import Temporal.

The six binaries core/cmd/

  • nori is the hosted API. It does its processing inside a request, and Cloud Tasks handles retries.
  • nori-local is the development API. It uses the same handler and adds a loop that runs every 2 seconds.
  • nori-worker is the Temporal worker that runs the inner loop.
  • computer-agent runs tools inside the Firecracker guest, or as a host proxy that forwards to the guest and stops the host when idle.
  • nori-connect-calendar is a one-time command that connects the Google calendar and saves its token.
  • nori-deliver is a repair tool. It redelivers pending commands to Temporal and repairs the records of finished tasks.
