Code map

Where to look when you want to read or change something across the Go engine, the host app adapter, contract suite and test workbench.

Go code lives under core/, the headless the host app Fetch adapter under integrations/embed/, shared JSON Schemas under contracts/assistant/, and the local test workbench under web/src/. Dependencies run in one direction: entrypoints build an app via platform, whose api routes and worker pool call conversation, task, permissions, scheduler, connections and connectors/mcp over state.

Infrastructure sits behind narrow contracts: state/postgres provides transactional JSONB records plus nori_task_leases, nori_user_wakes and LISTEN/NOTIFY, wake wraps durable wake/repair helpers, and secret handles AWS Secrets Manager and envelope-encrypted Postgres rows.

The four binaries core/cmd/

  • nori — Hosted service binary (--role=all|api|worker; HS256 service-authenticated HTTP API and/or unified Postgres-native worker pool, AWS adapters by default).
  • nori-local — Loopback development binary running both the HTTP API and the unified Postgres-native worker pool in one process.
  • nori-user — CLI for provisioning and inspecting user records in Postgres.
  • contracts-check — Strict validator for contracts/assistant/ JSON Schemas, Go round-trip decoding, generated TypeScript types and live HTTP scenarios.
