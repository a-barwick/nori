What loading changes

  • Loading only adds tool definitions to later model calls. The runtime checks each call against the task's scope.
  • The loaded set lasts until the task ends. The worker reads it back from the transcript, so it survives a worker restart.
  • A capability with no connected account still loads. Its result says it's unavailable, and its tools report the same if called.
What each catalog entry holds

The worker adds the catalog to the inner loop's instructions with today's date in the configured time zone. Each entry gives the capability's tools, account and availability, what to do on failure, and how to confirm a result.

The text changes at most once a day unless an account changes, so the provider's prompt cache still applies to the instructions.
