Roadmap

Implemented core capabilities of Nori and what remains for production rollout inside a host app.

AreaCapabilityStatus
Outer loop & memoryOne persistent thread per user, message batching, three-tier memory (Core, Daily Log, Working Memory) with session-idle extraction and AutoDream consolidation, quote-verified compaction and two-call prompt-injection provenance guard.Built.
Inner loopConcurrent Postgres-native tasks (task.Runner + worker.Pool), steering, Stop, spending ceilings, subtasks, durable questions and record-checked completion.Built.
Ports & MCPDigest-pinned extension registry, remote Streamable HTTP & local stdio MCP clients, compose scripts, SSRF netguard, provider-agnostic connections port and envelope-encrypted secret/rowstore.Built.
Permissions & approvalsDeny-wins rules engine and action-digest-bound typed approval cards with optimistic revision checks.Built.
Automations & goalsDeterministic recurring/once/watch schedules, goals and deduplicated in-app inbox delivery.Built.
Results & libraryVersioned saved results, conflict preservation, attachments and private S3/local storage.Built.
Clients & contractsHeadless Fetch handler (integrations/embed/adapter.mjs), slim Next.js workbench (web/), native SwiftUI iOS client (ios/), generated TypeScript types and strict contracts-check suite.Built.
Simulation & testingDeterministic simulation suite (core/internal/sim/) and 10-persona × 30-day virtual-clock evaluation harness (core/cmd/nori-sim/, sim/personas/, scripts/persona-sim/).Built.
Cloud runtime adaptersSingle binary (cmd/nori --role=all|api|worker), Postgres JSONB with leases and wakes, S3 or GCS artifacts, AWS Secrets Manager or Cloud KMS, OIDC verification and HS256 service auth.Built.
Host app production rolloutProvisioned AWS infrastructure, host app production identity binding, enterprise MCP gateway wiring and multi-identity soak testing.Planned
