Persistent computer

A small Linux machine that tasks use for shell and browser work. It keeps its files between runs.

“Check Saturday's weather in Tucson” reaches the computer as one browser call from the worker, and the page text comes back as its result.

  • Kept across guest restarts and host replacement: files, installed tools and the browser profile.
  • Lost on restart: running processes and open tabs.
  • Access goes through an IAP tunnel to a private guest IP, with no separate token.
  • Browser tabs share cookies, so tasks aren't isolated from each other.

Receipts make retries safe

The guest records the request and response for each operation ID before acknowledging. If a shell command's outcome is uncertain, the worker reads the receipt and doesn't run it again.

The host says when it's draining

When the host is stopping because it's idle, it rejects requests with a draining header before forwarding them. This is the one case where it's safe to reconnect and resend.

Jobs belong to a task

The guest runs each long shell job in its own process group and saves its state on disk. A job running during a restart is reported as lost.

Adapter calls, GCP-specific files and an AWS adapter

An AWS adapter designed

No AWS adapter exists and no instance type has been tried. It would need to supply the following.

RequirementWhat the adapter supplies
StatesA mapping from EC2 instance states (pending, running, stopping, stopped, shutting-down, terminated) onto the four states below. The last two mean the instance is gone, so they return an error.
StopA power-off from inside the host must leave the instance stopped, not deleted. The host proxy already requests that stop after 15 idle minutes.
ReachabilityA private path from the worker to port 8090 on the host. The guest RPC has no token, so this path is the only access control.
KVMA readable and writable /dev/kvm on the host. The host scripts load kvm_intel and install x86_64 builds, so the host must be Intel x86_64. Each instance type has to be checked for KVM before use.
DiskA workspace disk that outlives the instance and attaches to its replacement.
WiringA config type and one more branch in platform.Computer().

Adapter calls

An adapter with a power state implements three calls. A shared loop polls them once a second, reports Stopped only after the host has finished stopping, and never sends a start during Stopping.
