Deployment

Production targets AWS + Postgres + S3 using one distroless static Go binary (cmd/nori --role=all|api|worker); local development runs Postgres via Docker Compose.

Authentication boundary

Hosted deployments verify OIDC ID tokens (NORI_OIDC_ISSUER, NORI_OIDC_AUDIENCE) or the host app's verified session at the host layer, resolve the user, and call the Go API with 1-minute HS256 service tokens (nori-service). Only /healthz is unauthenticated.

Graceful drain & split roles

Run --role=api and --role=worker separately to scale horizontally. On SIGTERM, workers stop claiming new leases, drain in-flight runners up to 25 seconds to a checkpoint boundary, and release leases immediately for another replica.

Secrets and credentials

  • AWS SDK clients use workload IAM roles or the standard AWS credential chain.
  • Per-user MCP and connection credentials live in Postgres using envelope encryption (core/internal/secret/rowstore) wrapped by a 32-byte key from NORI_CREDENTIAL_KEY or NORI_CREDENTIAL_KEY_SECRET (AWS Secrets Manager).
  • S3 objects stay private under user-scoped artifacts/ prefixes with conditional writes that refuse overwrites.

Container images and rolling deploys

  • core/infrastructure/Dockerfile builds the static CGO_ENABLED=0 nori binary onto gcr.io/distroless/static-debian12:nonroot.
  • Because inner tasks checkpoint explicit state and receipts in Postgres rather than replaying workflow code, rolling deploys do not require pinned workflow build IDs; parked tasks resume cleanly on the new binary.
  • docs/Dockerfile and docs/deploy.sh package the static Dokyu output into an unprivileged nginx container serving X-Robots-Tag: noindex and Disallow: /.

Pausing and operations

  • Execution pause blocks new task admission while the conversation thread, saved history and waiting tasks stay readable. Nothing is cancelled.
  • Each worker pod runs a 60-second repair sweep reconciling nori_task_leases and nori_user_wakes against nori_records, replacing any separate reconciliation CLI.
  • nori-user provisions and manages user rows in Postgres.
  • Nori's repository provides application adapters, not provisioned AWS Terraform.
