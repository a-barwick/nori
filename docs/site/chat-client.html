Chat client

Independent conversations stream replies through the same authenticated web server and agent service as the assistant.

Chat clientSends “Total the parts in this CSV” with its assigned file ID.
↓ message through the Next.js server
Foreground chat serviceSaves the turn and sends this conversation's context to the outer model.
↓ requested CSV read
CSV readerChecks file assignment and returns rows as untrusted data.
↓ rows for the outer model's answer
Foreground chat serviceSaves reply text at most every 400 ms, then the final answer.
↓ numbered events with the changed messages
Chat clientApplies each event and reloads the saved chat when it falls behind.

Conversation controls

ControlBehavior
New conversationOpens an empty draft. The chat is saved when its first message or file is sent.
SendReuses the same message ID when retrying unchanged input after a failed request.
Stop replyStops the selected turn and preserves its saved partial text.
Delete chatRemoves the chat, its history and its files after a confirmation. It's refused while a reply or action is open.
Attach CSVUploads a file to this conversation and assigns it to the next message.

The sidebar lists saved chats, newest first. When the event stream ends, the client reconnects on its own. If the connection drops, it shows “Reconnecting…” until it's back.

The Svelte client is packaged with the web app. Both clients remain available while an assistant task waits or runs.

Tools and decisions

ToolAvailable behavior
CSV readingReads assigned CSV files up to 64 KiB. Larger files require the assistant.
Calendar readingReads the configured calendar through the shared tool implementation.
Calendar changes and emailShows the saved action with Approve this action and Decline buttons.
Background tasks and computerUse the assistant client for task dispatch, shell, browser, PDF or image analysis.

An approval names one saved question. While it waits, the reply shows “Waiting for your approval” and new messages are refused.

After Approve, the service sends the saved action and records the provider outcome. The action's text stays under its outcome.

Stop cannot undo an attempted write. Its outcome remains recorded even after the reply stops.

Saved context

  • The model receives this chat's messages, assigned file metadata and recorded tool results.
  • File metadata and tool results reach the model as user-role data, never as system instructions.
  • Assistant tasks, saved memories and other chats stay outside that context.
  • At the chat's length limit, a new message gets “This chat reached its length limit. Start a new chat.” Existing history remains saved.

Chat contextInput is refused at 64 saved messages or above 96 KiB of message text and operation data.
Tool resultResults above 16 KiB become an error record instead of entering the next model request.
Event streamThe service ends each stream after 150 seconds, and the client resumes from its last event. A client more than 500 events behind reloads the chat.
Owner nameThe agent service's optional NORI_OWNER_NAME names the person in the chat's instructions.
