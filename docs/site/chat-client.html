Chats

Independent chats open from the side panel's Chats tab and stream replies from the same agent service as the assistant.

Chats tabSends “Total the parts in this CSV” with its assigned file ID.
↓ message through the Next.js server
Foreground chat serviceSaves the turn and sends this conversation's context to the outer model.
↓ requested CSV read
CSV readerChecks file assignment and returns rows as untrusted data.
↓ rows for the outer model's answer
Foreground chat serviceSaves reply text as it streams, then the final answer.
↓ numbered events with the changed messages
Chats tabApplies each event and reloads the saved chat when it falls behind.

Conversation controls

ControlBehavior
New chatOpens an empty chat in the main area. The chat is saved when its first message or file is sent.
SendReuses the same message ID when retrying unchanged input after a failed request.
Stop replyReplaces Send while a reply streams. It stops that turn and keeps its saved partial text.
Back to NoriCloses the chat and shows the assistant conversation again.
Delete chatRemoves the chat, its history and its files after a confirmation. It's refused while a reply or action is open.
Attach a fileOffers CSV files, uploads the file to this chat and assigns it to the next message.

The Chats tab lists saved chats, newest first. The page address names the open chat, so a reload reopens it.

When the event stream ends, the web client reconnects on its own. If the connection drops, the chat shows “Reconnecting…” until it's back. Assistant tasks keep running while a chat is open.

Tools

ToolAvailable behavior
CSV readingReads assigned CSV files up to 64 KiB. Larger files require the assistant.
Background tasks and computerUse the assistant conversation for task dispatch, shell, browser, PDF or image analysis.

Stop preserves partial reply text and any recorded tool outcomes.

Saved context

  • The model receives this chat's messages, assigned file metadata and recorded tool results.
  • File metadata and tool results reach the model as user-role data, never as system instructions.
  • Assistant tasks, saved memories and other chats stay outside that context.
  • At the chat's length limit, a new message gets “This chat reached its length limit. Start a new chat.” Existing history remains saved.
Addresses and limits
ItemValue
Open chatThe page address carries ?chat= and the chat ID.
Browser requests/api/v1/conversations through the same owner-protected Next.js server.
Uploaded fileUp to 10 MiB. Foreground CSV reading has the lower 64 KiB limit.
Chat contextInput is refused at 64 saved messages or above 96 KiB of message text and operation data.
Tool resultResults above 16 KiB become an error record instead of entering the next model request.
Event streamThe service ends each stream after 150 seconds, and the web client resumes from its last event. A client more than 500 events behind reloads the chat.
InstructionsThe chat's system prompt is built from core/internal/prompts/chat.txt. It calls the person chatting the user and names no one.

Run and verification commands are in the repository README. Service API lists the conversation routes.
