What Nori takes from this

These are Nori's design conclusions, and the vendors don't state them.

  • Keep external tool execution and user files separated from the services that enforce permissions and protect credentials.
  • Give each task explicit status, ownership, cancellation and recovery behavior. A long chat history cannot track those.
  • Treat memory retrieval, scheduled triggers, tool execution and authorization as separate mechanisms.
  • Test changes in user instructions and permissions across intervening tasks, as well as tasks that go as planned.
  • Measure completed work, correction time and cost. Product pages only show intended behavior.
