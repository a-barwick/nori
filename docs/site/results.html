Results and files

A saved result should reopen later, and its records should show whether it reached the user.

Created→Checked→Delivered

These are separate facts. A saved result might not have reached the user yet, and a saved reminder timer doesn't show the reminder arrived.

What a result records

  • A stable ID and a place to find it.
  • The task that made it, and which instructions it answers.
  • The evidence behind it, and what's still uncertain.
  • Its revisions, so old versions stay as history.
