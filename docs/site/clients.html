Clients

The web app shows the assistant and its independent chats, and one agent service owns their saved state and execution.

Assistant conversationShows one conversation with Nori and its background tasks.
Chats tabShows separate chats and their streamed replies.
↓ messages, file uploads and user decisions

↓ HTTP requests with server credentials

↓ saved messages, tasks and conversation changes

The web client supports phone widths. Its side panel switches between Activity and Chats, and an open chat's back arrow returns to the assistant.

“Check Saturday's weather in Tucson” can keep running as an assistant task while “Read this CSV” runs in a separate chat.

Conversation boundaries

  • Chat messages, events, attachments and operations belong to one conversation.
  • New chats exclude assistant tasks, saved memories and other chats from model context.
  • The assistant and chats use the same verified sign-in, user scope and configured providers.

Service API describes the routes and replay behavior.

NORI_CLOUD=aws selects OIDC sign-in and signed web-to-API service tokens; GCP keeps IAP and service-account IAM. OIDC checks signature, issuer, audience, expiry and verified email. A host or login gateway supplies the ID token; Nori resolves its verified email to a provisioned user. See AWS configuration.
