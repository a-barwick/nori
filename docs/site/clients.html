For “Check Saturday's weather in Tucson”, the web client sends the words and shows the saved reply. The agent service builds the prompt, saves the task and owns its status.

What a client never does

  • Build prompts or send context. It only sends the user's own words and references.
  • Read layout hints from model output. The service removes them and sends typed parts.
  • Assume a command has finished because it was accepted.
  • Talk to a model provider directly.
