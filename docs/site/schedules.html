Requested and proactive

Requested

Remind me tomorrow at 9.

The user asked, so it's already authorized. Milestone 9.

Proactive

Your appointment ends at 1:45, and the meeting is 30 minutes away. Want me to find another time?

Nobody asked. The current proposal is to offer only. Milestone 11.

Task results aren't proactive messages

A result that arrives later belongs to a request the user made. It's always saved, and it doesn't count against any cap on proactive messages.

What the rest need

Recurring schedules

  • Local time across daylight saving, and business days
  • Skip and snooze
  • Exactly one catch-up after a missed run
  • List, change, pause and cancel
  • A report when nothing ran

Monitors

  • A threshold, a cadence and an end date
  • No alert unless the condition is met
  • No duplicate alerts

Proactive help is still being designed
