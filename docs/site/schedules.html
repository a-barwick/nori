Schedules and proactive help

Work scheduled by request, and work started by a trigger. They follow different rules.

Requested

Remind me tomorrow at 9.

The user asked, so it's already authorized. Milestone 9.

Proactive

Your appointment ends at 1:45, and the meeting is 30 minutes away. Want me to find another time?

Nobody asked, so it offers instead of acting. Milestone 11.

Task results aren't proactive messages

A result that arrives later belongs to a request the user made. It's always saved, and it doesn't count against any cap on proactive messages.
