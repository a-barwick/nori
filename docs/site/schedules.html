Triggers

TriggerFires
OnceAt a specific instant. A later time zone change does not move it.
RecurringBy a local start time, an IANA time zone and a recurrence rule. A repeated DST local hour runs once. A skipped hour advances to the next valid time.
WatchWhen a typed condition on a source changes, bounded by its cadence policy.

POST /v1/automations/preview previews upcoming fire times, standing access and missed-run handling before an automation is saved.

Exactly one occurrence per slot

  • The scheduler derives the occurrence ID from the automation ID, scheduled slot and schedule generation.
  • A duplicate wake or second scheduler pass finds the existing occurrence and does not start a second task.
  • Editing or cancelling an automation advances its generation. Unstarted slots from the previous generation never run.
  • The scheduler records a missed slot as skipped or expired, with a reason.
  • After every pass and edit, the scheduler saves the next due wake_at timestamp in nori_user_wakes with no delay cap. It emits NOTIFY nori_wake when a wake is due immediately.
  • The 60-second repair sweep and resume pass recover any missed wake.

In-app inbox delivery

  • Nori records running a task and delivering its result separately.
  • Deliveries target the built-in in_app destination, which creates one deduplicated inbox item under /v1/inbox that links to the task and its results.
  • Users acknowledge items with POST /v1/inbox/{id}/actions.
  • Nori has no Web Push or SMTP email delivery. Any other destination fails with destination_missing, so the host app can send external notifications.

Goals

A goal (/v1/goals) tracks a longer-running outcome with completion criteria, progress notes, blockers and next actions. It links to the tasks and automations working toward it.

A failed run leaves the goal unchanged. Completing a goal stops its attached automations unless the user chooses to keep them.
