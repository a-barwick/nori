System overview

Every box Nori runs on, and what each one is responsible for.

Firestore is the source of truth for what Nori has accepted, and Temporal is the source of truth for how far execution has got. The task view in Firestore is a projection of the workflow, and budget decisions are made inside the workflow.

Accepted, applied and completed are different states

A saved command only shows that it was accepted, and a tool attempt doesn't show that it had any effect. Nori's reply describes the furthest outcome the records support.

Chat keeps working when tasks are paused

The conversation wakes through Cloud Tasks or the local loop, which is separate from task delivery. Nori can still reply while task execution is paused.

The service owns shared state

Clients display state and send what the user wants to do. Anything two clients could disagree about belongs to the service.
