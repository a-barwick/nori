When a task ends

The turn that reports a task's end includes the answer, the unmet items and up to 8 KiB of the results the task cited. The outer model compares them and tells the user what is and isn't done. See Finishing a task.

Batching rules

ArrivalBehavior
First message, idleThe turn starts immediately.
Follow-up during a turnDrops unpublished output, waits 1 second after the latest follow-up, and restarts with all the inputs.
After 3 restartsFinishes the captured batch. Newer inputs wait for the next turn.
Task event during a turnSaved for the next turn. The current turn carries on.
Task panel answer or Stop buttonSkips Jev and the model, and goes straight into the same command path.

One message, several jobs

A single message can answer something, steer a task and start another. The reply text and one action per job come back in one response.

Like Saturday, should I wear shorts?

  • “Saturday” steers the weather task.
  • The shorts question waits for the forecast.
  • The reply answers it once the result arrives.
Provider behavior, recovery and response goals

The outer model is GPT-6.1 Sol at low reasoning, through the OpenAI platform API. Sol low replaced Muse after Muse omitted commands and rejected structured responses in local checks. The schema uses the existing command definitions, and no second model call forces dispatch.

Intro and task-notification turns return plain text and can't issue commands. If a response has actions without text, the runtime writes an acknowledgment from the accepted receipts.

Rejected responses stay in private attempt records and are excluded from later model history. Recovery reuses accepted command receipts and doesn't repeat the model call.

hold(task_id, question) saves a question without changing the task's instructions. A terminal event supplies the outcome for its answer.

Warm localhost targets agreed for milestone 4 are 100 ms for typing feedback, 1 second for durable command acceptance, and 2 seconds for visible saved status or read cancellation. Model latency and cold starts are measured separately.
