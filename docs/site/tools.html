Long shell jobs

running→finishedorstoppedortimed_outorlost
  • A job can run for up to 60 minutes, with up to 4 running per task. It belongs to the task, so a correction or a question leaves it running.
  • job_wait makes no model calls. An activity reads the job's state every 15 seconds and saves the latest output line as the task's progress, which the web client and the outer loop read.
  • A wait is a chain of activities of up to 200 seconds each, because a pending activity is what wakes a request worker. One worker stays running while a task waits on a job.
  • The task can't propose completion while a job it started is running, and terminal cleanup stops any job still running.
  • A running job holds off the computer's idle stop. If the guest restarts or the computer stops, the job's state is lost, and the runtime never reports it as finished.

Reading a screenshot

  • screenshot_inspect sends one saved image and one question to the task model in a separate call with no tools.
  • Only the text answer joins the task's history. The image isn't resent on later turns, and text inside it can't call a tool.
  • The cost counts against the task's budget. A call that was sent without a reported cost stops the task as cost unknown.
  • The completion check reads that text answer, because Jev doesn't receive images.

The calendar connection

  • nori-connect-calendar opens one Google consent screen for read-only access, then saves the refresh token and the account name in .env. Production reads them from Secret Manager.
  • The refresh token stays on the worker. It doesn't reach the computer, the model or a saved result.
  • calendar_read covers the primary calendar and up to 9 others selected in Google Calendar. It leaves out attendees and descriptions.
  • If the account isn't connected or Google refuses the token, the tool returns available: false and the task says so. An OAuth app in Google's testing state loses its refresh token after 7 days.

The capability catalog

The worker adds a short catalog to the inner loop's instructions, along with today's date in the configured time zone.

FieldExample
Name and toolsGoogle Calendar read (calendar_read)
AccountThe connected account, or none connected
AvailabilityAvailable, or unavailable: not connected
On failureTell the user it needs connecting. Never guess events.
  • A missing credential leaves the tool in place, and the tool reports itself unavailable. The model can tell a missing capability from one it didn't pick.
  • The catalog grants nothing. Tool descriptions and tool output are data, and the runtime checks each call when it runs.
  • Each search charges the task's budget $0.005, Brave's listed price on Oct 31, 2026. A failed search isn't retried automatically.
