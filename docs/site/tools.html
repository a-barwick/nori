Confirming a change

A tool that changes something must come with a way to confirm the change. The inner loop runs the confirmation and cites it, and lists anything it couldn't confirm as unmet.

ToolHow the change is confirmed
job_startThe wait returns the end state, exit code and output.
job_stopIts result is the final state.
shellThe exit code shows the command ran. A follow-up read, such as a file count, shows its effect.
calendar_create, calendar_moveThe result has Google's status and the event ID, and a follow-up read shows the event.
email_sendThe result has Google's status and the message ID, and a follow-up read shows the sent message.

The calendar and email write tools wait for the user. See Approvals and writes. For work outside a task's request, see Subtasks.

Job limits, screenshots, calendar and the catalog
  • A job can run for up to 60 minutes, and a task can have 4 running at once.
  • Waiting on a job makes no model calls. The task's progress shows the latest output line.
  • A task can't finish while its job is running, and task cleanup stops any job left running.
  • If the computer restarts or stops, the job is killed and reported as lost, never as finished.

screenshot_inspect sends one saved image and one question to the task model in a separate call with no tools. Only the text answer joins the task's history, so text inside an image can't call a tool. The cost counts against the task's budget.

nori-connect-calendar opens one Google consent screen for calendar and email access, then saves the refresh token and account name in .env and Secret Manager. Production reads them from Secret Manager, and the token stays on the worker. calendar_read covers the primary calendar and up to 9 others selected in Google Calendar.

If the account isn't connected or Google refuses the token, the calendar or email tool returns available: false and the task says so. An OAuth app in Google's testing state loses its refresh token after 7 days.

The worker adds a short catalog to the inner loop's instructions, with today's date in the configured time zone. Each entry gives the capability's tools, account and availability, what to do on failure, and how to confirm a result. A missing credential leaves the tool in place, and the tool reports itself unavailable.

Each search charges the task's budget $0.005, Brave's listed price on Oct 31, 2026.
