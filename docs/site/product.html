How we measure progress

Twelve technical capabilities
CapabilityWhat it requires
Responsive chat, durable tasksConversation stays available while workers run with checkpoints.
Explicit task stateTasks, dependencies, results and blockers are saved.
Separate memory storesUser knowledge, history, procedures, active work and authority, with scope and source.
Context assemblyRelevant context is provided, and older context stays retrievable.
Persistent environmentFiles, browser sessions, tools and storage recover across sessions.
Permission enforcementThe same rules cover connectors, browsers, shell commands and delegated tasks.
Tool discoveryOnly the tools a task needs are exposed, with schemas, identities and failure behavior.
Computer coordinationObserve, act and verify loops, recovery, and access control for shared sessions.
Scheduling and eventsTime zones, recurrence, retries, de-duplication, cancellation and notification rules.
Artifact storageStable IDs, versions, previews and links back to tasks.
Cost and latency controlsBounds on retries, concurrency, runtime and spending.
Completion evidenceOutcomes are checked, and activity history records actions, failures, costs and approvals.
