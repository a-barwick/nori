Budgets and controls

Nori counts model spending and uses four controls to pause or stop work.

Inner model callThe task for “Check Saturday's weather in Tucson” calls its model.

Workflow adds to spentThe task's spent figure grows between calls.
↓ spent reaches $1
Task waits at $1It saves a budget question, and continue adds $1.
  • The $1 limit is checked between calls, so it isn't a hard cap on billing.
  • Each web search adds $0.005 to the task's spent figure.
  • An unknown cost fails the task, and a subtask's unknown cost also fails its parent.
  • A subtask's cost counts against its parent's budget, and each check reads the shared total from Firestore. Each running subtask can overrun by one model response and its tool calls.
  • Outer-loop and Jev classifier calls write a usage row before the provider call.

Four controls

Task budget · $1

Applies to a top-level task and its subtasks. When it runs out, the task that reached it saves its progress and asks, and continue adds $1 to the shared task budget.

Input wait

The task parks with its question and records intact. No timer ends it.

Pause

Blocks new execution for all tasks. Workers exit and the computer stops, while chat keeps working.

Task Stop

Ends one task and its subtasks, and confirms their operations and shell jobs stopped.

Operating rules

  • Cloud Run and Agent Runtime run with a minimum of 0 and a maximum of 1 instance.
  • When live work finishes, worker pools scale to zero and the computer stops.
  • The computer's guest receives no cloud credentials.

If the development allowance refuses an inner request before dispatch, the task reports the refusal without marking its cost unknown.

Provider pricing and enforcement

Pricing checked October 31, 2026: Sol standard tier costs $2 per million input tokens, $0.10 per million cached input tokens and $10 per million output tokens. Nori disables implicit cache writes and refuses requests above the 272K input pricing threshold. Terra's ceilings remain $1 input and $5 output per million tokens.

Nori's adapters enforce the shared ledger, and calls outside them are not intercepted. The direct OpenAI project key has no native per-chat cap, and OpenRouter has a scoped native key limit.
