Privacy policy

Nori is a personal assistant that one person runs for their own use. It isn't offered to the public, and no one else can sign in to it.

Google data Nori uses

When its owner connects a Google account, Nori asks for these permissions:

  • Read the owner's calendars and events, and create or change events the owner approves.
  • Send email from the owner's account. Each email a task prepares is shown to the owner and sent only after approval. Nori also emails the owner their own reminders and task results.
  • Read the headers of recently sent mail, to check whether an approved email was sent.

Nori uses this data only to carry out what the owner asks. It doesn't use Google data for advertising, doesn't sell it, and doesn't use it to train models. Nori's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Where data goes

  • Conversation, task records and connection tokens are stored in the owner's Google Cloud project.
  • To answer a request, the relevant text, which can include calendar details, is sent to language model providers: OpenAI, and model providers reached through OpenRouter.
  • Web searches go to Brave Search, and driving times to the Google Maps Routes API.
  • Error reports from the web app go to Sentry.

No data is shared with anyone else.

Keeping and deleting data

Data stays in the owner's project until the owner deletes it. Disconnecting the Google account in Google's account settings stops all access. To ask about this policy, use the developer contact email on Nori's Google sign-in screen.
