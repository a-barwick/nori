# Nori technical debt audit

November 25, 2026 · Baseline `bcaa97d`

The audit covers Go core and workers, Postgres, the web and iOS clients, shared contracts, the host adapter, the persona harness and release tooling. The worktree cleanup removes prose comments. The baseline findings below record the original evidence and acceptance criteria.

## Remediation

| Area | Result |
| --- | --- |
| Dependencies | Updated Next.js and its ESLint config to 16.4.6, Sentry to 11.18.0, the affected OpenTelemetry modules to 1.47.0, and `golang.org/x/net` to 0.62.0. The core minimum and container builder use Go 1.26.11. The web and Go dependency scans report zero vulnerabilities. |
| Model routing and accounting | Web and iOS share model-selection fixtures and use defaults when capabilities are unavailable. A new turn rejected because its selected profile is unavailable retries with the same turn ID and default routing. Web pending replays retain their original selection. Tests reach the selected provider through both Go turn endpoints and inspect the iOS wire payload. Model exposure settles once on response completion. The gateway reads usage from long SSE streams, including split Anthropic usage, and records an estimate when a response is incomplete. |
| Web and iOS state | Web resource subscriptions share polling per path, release inactive paths, and finish refreshes even when a newer mutation supersedes them. Drafts and pending messages are account-scoped. iOS ignores responses from prior sessions after sign-out or account changes and reports partial memory refresh errors. Routine previews and saves use the same typed value, including the end date in the routine's timezone. |
| Postgres memory and quota | Memory reads scan bounded pages and return complete daily groups, including a day spanning multiple pages. In a 730-day local history, reading the latest seven days took 0.55 ms/op compared with 25.3 ms/op for the entire history. Quota admission aggregates exact rolling windows inside the existing serializable reservation transaction. In a local 5,000-row read benchmark, fetch and decode took 27.4 ms/op and 11 MB/op. The aggregate took 8.7 ms/op and 1.7 KB/op. The benchmark measures the read path for one account. The per-account serialization point and exact rolling windows remain. |
| Upload lifecycle | Metadata is reserved before the blob write. The worker reconciles incomplete uploads after one day and unattached uploads after seven days. Committing an attachment retains the upload atomically with its parent operation. Existing uploads keep their previous lifecycle. Historical blobs without a metadata record need a separate inventory. |
| Operations | Capabilities advertise no conversation mode when the assistant is disabled, and both turn endpoints return 501. Migrations run in bounded transactions, record checksums, and support a Cloud Run migration job. The deployment script gates web rollout on core readiness and checks web afterward. With a provisioned smoke token file it also verifies authenticated access to core through web. Production rollout, bucket lifecycle settings, and live provider billing were outside the local verification. |
| Maintenance | Removed the 37 reported unreachable Go functions and methods, confirmed unused web and Swift symbols, and stale assignments. Extracted iOS memory operations, web memory search, and persona runtime setup. The persona stub mode uses dummy credentials under the test profile and parallel standalone runs use isolated databases. |
| Tests and CI | React hook tests use the public DOM renderer and `act`. Browser coverage runs the standalone production build and exercises sign-in, queued turns, reconnect, approval, profile revocation, identity switching, file downloads, and routine scheduling across daylight saving. A separate lease-renewal test now waits for watcher startup before advancing the simulated clock. CI now checks fixture drift and runs the production build, dependency scans, browser, Swift, Python, adapter, deployment, and isolated persona checks. |

## Baseline shortcuts and loose ends

| Area | Finding and follow-up |
| --- | --- |
| Postgres memory history | `MemoryLogs` fetches and decodes every matching shard before grouping by day and applying the limit. Both the memory endpoint and routine dream work call it. Bound the query by day at the database, then read all shards for the selected days. Benchmark with long-lived accounts and a day that spans several shards. [Query](../core/internal/state/records/memory.go#L37) · [Dream caller](../core/internal/conversation/dream.go#L100) |
| Postgres quota admission | Each enabled admission loads the full usage window inside a serializable transaction and writes the same per-user contention record. That supplies atomicity and makes hot-account admission work grow with attempts in the window. Measure latency and retry rates on real Postgres, then evaluate transactional time buckets with replay-safe reservation IDs. [Admission](../core/internal/state/records/database.go#L176) |
| Upload lifecycle | Upload bodies and metadata commit separately. A DB failure after the blob write can leave orphaned bytes, and a successful upload may never be attached. The repository's upload path has no reclaim job or retention policy. Confirm bucket lifecycle settings, then add reconciliation for uncommitted uploads and an explicit retention rule for unattached files. Test a failed metadata write, a retry and a persisted attachment. [Upload orchestration](../core/internal/conversation/uploads.go#L9) · [Upload metadata](../core/internal/state/records/uploads.go#L14) |
| Chat-only mode | The local runbook advertises `/users/<id>/v1/conversations` with background tasks disabled. The current app creates no conversation runner in that mode and the assistant chat endpoints are gated to 501. The documented plain conversations route has no registered handler. Decide whether to restore chat-only mode or document the flag as disabling the assistant. Test the chosen behavior from the documented client entry point. [Runbook](../core/infrastructure/local/README.md#L35) · [App wiring](../core/internal/app/app.go#L140) · [Routes](../core/internal/api/http.go#L60) |
| iOS session state | `signOut` clears the store while ordinary requests can still be suspended. Methods such as `refreshSession`, `refreshMemory` and `sendMessage` apply responses after an await without checking the original identity. A late old-session response can repopulate state. Add an identity generation or cancellation boundary and cover sign-out and rapid re-auth with delayed responses. Separately surface partial memory refresh failures, which currently disappear into `try?`. [Sign-out and refresh](../ios/NoriKit/Sources/NoriCore/Store/NoriStore.swift#L342) · [Memory refresh](../ios/NoriKit/Sources/NoriCore/Store/NoriStore.swift#L546) · [Send](../ios/NoriKit/Sources/NoriCore/Store/NoriStore.swift#L707) |
| Web resource lifetime | The client cache, subscription entries and versioning flags are keyed by path for the lifetime of the tab. Unmount removes callbacks and timers, but the keys remain and prefix invalidation refetches old routes. Bound cache retention and scope it to the active identity. Deduplicate focus, visibility and polling work for shared resources. Check a long navigation session and a session switch. [Resource hook](../web/src/lib/assistant/useResource.ts#L8) |
| Model profiles | Web and iOS maintain separate selection normalization logic and already differ on missing capabilities. The env template also omits model picker, profile override and local model settings. Keep the clients aligned with fixtures that express server defaults, missing capabilities and removed profiles. Document the local and hosted settings. [Web normalization](../web/src/lib/assistant/context.tsx#L42) · [iOS normalization](../ios/NoriKit/Sources/NoriCore/Store/NoriStore.swift#L130) · [Settings loader](../core/internal/settings/models.go#L141) |
| Routine editing | The web form builds the recurrence in the selected timezone and converts the end date using the browser's timezone. The value can expire on the wrong schedule day when those zones differ. Resolve the end date in the routine's timezone and test a browser in a different zone across a daylight-saving transition. The form also suppresses hook dependency lint while using derived trigger and destination keys. Build the preview and submission from one typed form state. [Routine form](../web/src/components/assistant/RoutinesScreen.tsx#L562) |
| Migration operations | App startup applies every pending migration in one transaction, records filenames only and disables the statement timeout within that transaction. This makes cold starts compete for migration locks and gives no drift check after a filename has been applied. Prior persona runs observed lock-table exhaustion on concurrent cold starts. Add an explicit migration release step and fresh/upgrade schema verification. Keep the migration ledger compatible with historical filenames. [Migrator](../core/internal/state/postgres/database.go#L811) · [Prior migration failure](vst-findings.md#44-harness--rubric-fixes) |
| Maintenance hotspots | The iOS store is over 1,500 lines, the web memory screen is over 1,300 and the persona runner is over 2,700. They combine state ownership, side effects and presentation or orchestration. Split them only along proven seams, starting with iOS identity-scoped loading, memory editor vs. search, and persona setup vs. event execution. [iOS store](../ios/NoriKit/Sources/NoriCore/Store/NoriStore.swift) · [Memory screen](../web/src/components/assistant/MemoryScreen.tsx) · [Persona runner](../scripts/persona-sim/runner.py) |

## Comment cleanup

Removed 7,139 prose comment tokens across 422 tracked files, including generated TypeScript. Updated both generators so comments stay absent after regeneration. The deploy command's help is now command output, and operational details about env files, provider key isolation and migration ordering are in the core README.

The retained comment-shaped lines carry tool semantics, including Go embeds and module metadata, the Swift tools version, the Xcode project marker, executable shebangs, Docker syntax and lint/type directives. Protocol data, runtime prompts and Python docstrings remain part of the application or its documentation.

Token comparisons found identical Go tokens outside the fixture generator, identical emitted JavaScript outside the TypeScript generator, identical Swift tokens, and identical Python syntax trees. The parsed Xcode project matched the baseline. Verification used local runtimes, stub providers and source review.
